# Databricks Portfolio

This repository was created to explore Databricks features through practical projects and apply software engineering and data engineering best practices along the way.

It will include experiments with notebooks, Python, SQL, Lakeflow Jobs, Spark Declarative Pipelines, Unity Catalog, automated deployment, infrastructure as code, testing, and CI/CD. Each project is intended to be reproducible, version-controlled, and organized around a clear use case.

The repository will evolve as new Databricks features and implementation patterns are explored.
